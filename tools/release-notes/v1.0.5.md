# v1.0.5

**本版脚本逻辑无变化**（`@version` 1.0.4 → 1.0.5），改动都在部署工具侧：

- zy.py 新增「本地 js 直推」：直接读本机 `microsoft-rewards.user.js`，通过 CDP 推给脚本猫覆盖已装脚本，
  不再依赖商店同步；找不到本地文件才退回跟商店比版本。
- 已装版本更旧 → 推；版本相同但内容变了（改了代码忘了改版本号）→ 也推；已装更新 → 不降级。
- 覆盖后自动启用脚本、关闭该脚本的商店自动检查（防止旧版被盖回）；uuid 变化时自动重写 Cookie 授权。
- 新增开关：`SC_LOCAL_UPDATE`（默认 1）、`SC_LOCAL_SCRIPT`（路径）、`SC_LOCAL_KEEP_STORE_CHECK`（默认 0）。
- 手动推一次：`python3 zy.py --update-script`；看状态：`python3 zy.py --script-status`。
